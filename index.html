Mnemoq

Live · in use

An AI study coach for Bangladeshi admission tests, built on the mistakes students actually make.

Students pick an exam path (BUET Engineering, NSU Admission or Medical MBBS/BDS) and set their exam date. Mnemoq diagnoses their weak topics, turns every mistake into a review card, and plans what to study each day until the exam. I'm developing it with feedback from early users.

  • AI diagnostic: generates topic-tagged questions for each exam section. A second AI pass re-solves every question and drops any it disagrees with, so a wrong answer key can't mis-diagnose a student.
  • Exam readiness score: a 0–100 estimate per section that starts from the diagnostic and shifts toward the student's recent recall rate and mock results.
  • Timed mock tests with original question banks (quant questions generated by a Python script that computes every answer), AI essay marking against a four-part rubric, and reports that turn missed questions into cards.
  • Mistake-to-memory loop: quick add, AI-drafted memory hooks and similar MCQs, then typed or multiple-choice review on a spaced schedule.
  • Daily missions, streaks and push reminders that respect each person's time zone and quiet hours.
  • Profiles, Supabase accounts, Bangla and English interface. AI keys stay on the server with per-user daily limits and a fallback provider.

Seller Storefront

Template · demo live

A reusable online shop for Facebook sellers in Bangladesh.

Most small sellers in Bangladesh run entirely on a Facebook page, answering “price koto?” in the comments. This template gives them a proper catalog. One data file holds the shop name, products and prices, so a new shop can be set up by editing that file.

  • Bangla interface, product pages, a shopping bag and an order form
  • Orders go straight to the seller's WhatsApp as a formatted message
  • Built and tested for low-cost Android phones on mobile data

Jonopod জনপদ

MVP in development

Evidence-based local development planning for Bangladesh, upazila by upazila.

A national planning platform that turns public data on population, health and services into clear, printable briefs for local planners. The MVP covers one upazila, Sandwip in Chattogram, to prove the approach before it scales across the country. The design rule is data integrity: no invented numbers.

  • Every figure keeps its original value, source, reference year and geographic level
  • Missing data shows as “unavailable”, never as zero; unverified records stay flagged
  • Started by checking the dataset against source tables and resolving discrepancies in population and health-facility records
  • Print-ready layout that exports to PDF from the browser
